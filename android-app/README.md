# RYZON AI — Android App

Flutter starter foundation for the RYZON AI cartoon movie studio.

## Run locally

1. Install Flutter SDK and Android Studio.
2. From this directory run: `flutter pub get`
3. Connect an Android device or start an emulator.
4. Run: `flutter run`

## Current foundation

- Dark Material 3 home screen
- Eight studio feature entry points
- Basic feature detail screens
- Flutter package and lint configuration

## Not connected yet

Photo/video processing, face detection, image or video generation, voice, music, live camera effects, authentication, database, cloud storage and payments still require implementation and service configuration. This commit is a UI foundation, not a finished AI app or APK.
